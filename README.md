# Excel Assignment 2 — Data Cleaning and Transformation

## 📌 Assignment Overview

This assignment focuses on cleaning, transforming, and formatting a product dataset using Microsoft Excel.

The objective is to identify data quality issues, clean inconsistent values, remove duplicate records, transform Product IDs, and improve data presentation using Excel features.

---

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- Find & Replace
- Remove Duplicates
- Text Functions
- Conditional Formatting
- Data Bars
- Currency Formatting

---

## 📊 Data Cleaning & Transformation Steps

### Step 1 — Missing Value Analysis

- Identified missing values in the dataset.
- Found 3 missing Price values.
- Missing Price values were kept blank.
- Missing Category values were corrected.

**Observation:**  
Identified missing values in the dataset. The 3 missing Price values were kept blank, while the missing Category values were corrected.

---

### Step 2 — Product Name & Category Corrections

- Corrected inconsistent Product Name values.
- Corrected inconsistent Category values.
- Standardized the dataset for consistency.

**Observation:**  
Corrected inconsistent Product Name and Category values to maintain clean and consistent data.

---

### Step 3 — Duplicate Removal

- Identified duplicate records.
- Removed duplicate records using Excel's **Remove Duplicates** feature.
- Improved data consistency by avoiding repeated records.

**Observation:**  
Duplicate records were identified and removed to improve data consistency and avoid repeated records.

---

### Step 4 — Product ID Split & Product Brand

- Split the **Product ID** into:
  - Manufacturing Date
  - Country Code
- Created a new **Product Brand** column.
- Combined Brand Name and Product Name.

**Observation:**  
Product ID was split into Manufacturing Date and Country Code. Product Brand was created by combining Brand Name and Product Name.

---

### Step 5 — Price Currency Formatting

- Applied currency formatting to the Price column.
- Standardized the presentation of price values.
- Used the `$` currency format.

**Observation:**  
Price values were formatted consistently as currency for clear and professional presentation.

---

### Step 6 — Price Data Bars & Electronics Highlighting

- Applied **Data Bars** to the Price column.
- Highlighted **Electronics** category values.
- Improved visual identification and comparison of price values.

**Observation:**  
Data Bars were applied to the Price column, and Electronics category values were highlighted for easy identification.
